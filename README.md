# 💈 BarberForce

> Sistema completo de gerenciamento para barbearias desenvolvido na plataforma Salesforce

[![Salesforce API](https://img.shields.io/badge/Salesforce%20API-65.0-00a1e0?logo=salesforce)](https://developer.salesforce.com/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## 📋 Sobre o Projeto

O **BarberForce** é uma solução robusta desenvolvida utilizando Salesforce DX para gerenciar todos os aspectos de uma barbearia moderna. O sistema oferece funcionalidades completas para agendamento, gestão de clientes, controle financeiro e muito mais.

## ✨ Funcionalidades

- 📅 **Agendamento Online** - Sistema inteligente de marcação de horários
- 👥 **Gestão de Clientes** - Controle completo do histórico e preferências
- 💰 **Controle Financeiro** - Acompanhamento de receitas e despesas
- 📊 **Relatórios e Dashboards** - Análises visuais e insights de negócio
- 👨‍💼 **Gestão de Barbeiros** - Controle de agenda e comissões
- 🔔 **Notificações Automáticas** - Lembretes por SMS e e-mail
- 📱 **Mobile First** - Interface otimizada para dispositivos móveis

## 🚀 Tecnologias Utilizadas

- **Salesforce DX** - Framework de desenvolvimento
- **Apex** - Linguagem backend
- **Lightning Web Components (LWC)** - Framework frontend
- **Node.js** - Ferramentas de desenvolvimento
- **ESLint** - Análise estática de código
- **Prettier** - Formatação automática
- **Jest** - Testes unitários
- **Husky** - Git hooks
